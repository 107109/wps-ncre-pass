# 计算机二级 WPS Office · 一页上岸

一个单页备考台的商品页与激活版入口。

- `index.html`：商品页，可自由转发，含 5 道免费试做题。
- `s/`：每位买家一个专属页面。题目、答案、解析均以 AES-256-GCM 加密存放，**需要卖家发放的激活码才能解锁**；本仓库不含任何密钥或激活码。
- 解锁后进度保存在买家本机浏览器，不上传任何数据。

题目内容整理自教育部教育考试院「试题选登」公开样题与公开免费课程资源。

- `grade.html`：公开的智能批改体验站，上传答题纸/截图，本机识别答案并自动判分；从已解锁的专属卷可一键带入完整 60 题。图片与答案不上传服务器。
